# Last Christmas dancer and quicker reopening

Door 23 uses the owner's new green-screen dance video, keyed locally and
encoded as H.264 with RGB and alpha side by side. The original dance starts
at 29 seconds in the door's exact Last Christmas recording. Its own analyzed
beat grid controls the existing player synchronizer. The 12-beat phrase
repeats; beat analysis still needs the owner's listening review. Doors 1–4
retain their previous video. Door 5 remains a local experiment.

Already half-open doors take 2400 ms to reopen, versus 4800 ms for an unopened
door. A cached 2400 ms creak is synthesized at its original pitch, matching
the shorter animation. Reduced-motion users retain immediate popup display.
The browser tests cover first opening, repeat opening, persisted progress,
matching audio duration, YouTube playback, and account/history behavior.
Dance tests cover the 29-second anchor and timing across every registered song.

Only runtime media, timestamps and application code are published. Original
videos, analysis audio, local preview servers and private configuration stay local.
